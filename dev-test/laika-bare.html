Laika CMS — bare entry

This page loads laika-cms-bare.js, the bundle-size-conscious entry point. The full laika.html bundle eagerly registers every Decap backend, widget, editor-component, and locale (≈10 MB). The bare entry skips those auto-registrations and exposes the public Registry so the consumer can opt in to only what they actually use.

Real-app usage pattern

Run this in a bundler-driven project (vite, webpack, esbuild, etc.) so the consumer's tree-shake picks only the modules registered: 

import {
  CMS,
  init,
} from '@laikacms/decap-cms/laika-app/bare';
import { GitHubBackend } from '@laikacms/decap-cms/backend-github';
import widgetString from '@laikacms/decap-cms/widget-string';
import widgetRichtext from '@laikacms/decap-cms/widget-richtext';

CMS.registerBackend('github', GitHubBackend);
CMS.registerWidget(widgetString.Widget());
CMS.registerWidget(widgetRichtext.Widget());
init();
